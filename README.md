# GharSetu Static Site

This repo is ready to import into Vercel as a static website.

## Vercel Import Settings

- Framework Preset: `Other`
- Root Directory: `.`
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: leave empty

## Environment Variables

None required.

This project is plain HTML, CSS, JavaScript, and local SVG assets. There is no backend, no runtime API, and no secret key currently needed for deployment.

## Notes

- The contact forms are UI-only right now and do not submit to a backend.
- Google Fonts are loaded from `fonts.googleapis.com` and `fonts.gstatic.com`.
- The nested Gurgaon route is served from `gurgaon/builder-floors/index.html`.
